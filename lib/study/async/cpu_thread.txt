# CPU 스레드(Thread) 개념과 동기/비동기 작업

## CPU 스레드(Thread)란?

스레드는 프로세스 내에서 실행되는 작업의 단위입니다. 하나의 프로세스는 여러 개의 스레드를 가질 수 있으며, 각 스레드는 독립적으로 실행됩니다.

### 스레드의 특징:
- 같은 프로세스 내의 스레드들은 메모리 공간을 공유합니다
- 각 스레드는 고유한 스택(Stack)을 가집니다
- 컨텍스트 스위칭 비용이 프로세스보다 적습니다
- CPU 코어가 여러 개일 때 병렬 처리가 가능합니다

## 동기(Synchronous) 작업

### 동기 작업의 개념:
동기 작업은 하나의 작업이 완료될 때까지 다음 작업을 기다리는 방식입니다.
작업이 순차적으로 실행되며, 이전 작업이 끝나야 다음 작업이 시작됩니다.

### 동기 작업의 장점:
1. **단순한 코드 구조**: 순차적으로 실행되어 이해하기 쉽습니다
2. **디버깅 용이**: 실행 흐름이 명확하여 오류 추적이 쉽습니다
3. **데이터 일관성**: 작업 순서가 보장되어 데이터 무결성을 유지하기 쉽습니다
4. **예측 가능한 실행**: 실행 순서와 결과를 예측하기 쉽습니다

### 동기 작업의 단점:
1. **성능 저하**: 시간이 오래 걸리는 작업이 있으면 전체 프로그램이 멈춥니다
2. **자원 비효율성**: 대기 시간 동안 CPU가 유휴 상태가 됩니다
3. **사용자 경험 악화**: UI가 블로킹되어 응답성이 떨어집니다
4. **확장성 제한**: 동시에 많은 요청을 처리하기 어렵습니다

### 동기 작업 예시:
```dart
// 동기적으로 파일 읽기
String readFileSync() {
  String content = File('data.txt').readAsStringSync();
  print('파일 읽기 완료');
  return content;
}
```

## 비동기(Asynchronous) 작업

### 비동기 작업의 개념:
비동기 작업은 특정 작업의 완료를 기다리지 않고 다른 작업을 동시에 실행할 수 있는 방식입니다.
작업을 시작한 후 완료될 때까지 기다리지 않고 다른 작업을 계속 진행합니다.

### 비동기 작업의 장점:
1. **높은 성능**: 여러 작업을 동시에 처리하여 전체 처리 시간을 단축시킵니다
2. **응답성 향상**: UI가 블로킹되지 않아 사용자 경험이 개선됩니다
3. **자원 효율성**: CPU와 메모리를 효율적으로 사용합니다
4. **확장성**: 많은 동시 요청을 처리할 수 있습니다
5. **논블로킹**: 시간이 오래 걸리는 작업도 다른 작업에 영향을 주지 않습니다

### 비동기 작업의 단점:
1. **복잡한 코드 구조**: 콜백, Future, async/await 등 복잡한 개념이 필요합니다
2. **디버깅 어려움**: 실행 순서가 예측하기 어려워 오류 추적이 복잡합니다
3. **경쟁 상태(Race Condition)**: 공유 자원에 대한 동시 접근으로 예상치 못한 결과 발생
4. **메모리 누수 위험**: 콜백이나 리스너가 적절히 해제되지 않으면 메모리 누수 발생
5. **학습 곡선**: 개발자가 비동기 프로그래밍 패턴을 이해해야 합니다

### 비동기 작업 예시:
```dart
// 비동기적으로 파일 읽기
Future<String> readFileAsync() async {
  String content = await File('data.txt').readAsString();
  print('파일 읽기 완료');
  return content;
}

// 여러 작업을 동시에 실행
Future<void> multipleTasksAsync() async {
  Future<String> file1 = readFileAsync();
  Future<String> file2 = readFileAsync();
  
  List<String> results = await Future.wait([file1, file2]);
  print('모든 파일 읽기 완료: ${results.length}개');
}
```

## 동기 vs 비동기 선택 기준

### 동기 작업을 사용해야 하는 경우:
- 작업의 순서가 중요한 경우
- 간단한 로직으로 충분한 경우
- 데이터 일관성이 매우 중요한 경우
- 디버깅과 유지보수가 우선인 경우

### 비동기 작업을 사용해야 하는 경우:
- 네트워크 요청, 파일 I/O 등 시간이 오래 걸리는 작업
- UI 응답성이 중요한 애플리케이션
- 높은 동시성이 필요한 서버 애플리케이션
- 성능 최적화가 중요한 경우

## Flutter/Dart에서의 비동기 처리

Dart는 단일 스레드 언어이지만 이벤트 루프(Event Loop)를 통해 비동기 작업을 효율적으로 처리합니다:

1. **Future**: 미래에 완료될 작업을 나타냅니다
2. **async/await**: 비동기 코드를 동기 코드처럼 작성할 수 있게 해줍니다
3. **Stream**: 연속적인 데이터 흐름을 처리합니다
4. **Isolate**: 진정한 병렬 처리를 위한 격리된 실행 환경입니다

이러한 도구들을 적절히 활용하면 효율적이고 반응성 있는 애플리케이션을 개발할 수 있습니다.
